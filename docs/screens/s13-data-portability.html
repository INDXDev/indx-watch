Cloudflare からの出口

D1 → SQLite / PostgreSQL、R2 → S3 互換、Access → 任意の OIDC プロキシ、Browser Run → ローカルの Playwright。すべてフル書き出しから移せます。

置き換え先の一覧（SPEC-10）

目的

データが Cloudflare や INDX Watch に閉じ込められないことを、利用者がいつでも確かめられるようにする。手元の作業コピー、書き出し、取り込み、別アカウントへの複製を 1 か所から始められるようにする。

注記

  1. 1変更番号は sync_changes の最新 rev。最終フル書き出しは毎週の自動バックアップ（data_transfers）。
  2. 2コマンドはプロジェクトキーを埋め込んで表示。コピーボタンは navigator.clipboard。Git に入れる範囲の選択は watch.toml の [sync] commit に反映したプレビューを出すだけで、サーバーには保存しない。
  3. 3方式は login_sessions.auth_kind（cli_oauth / cloudflared のトークン / service_token）。遅れ = 現在の rev − その接続が最後に取り込んだ rev。「接続を切る」は Access のセッション失効（S12 と同じ API）。
  4. 4ログを含める選択肢は admin にだけ表示。書き出しは ExportWorkflow で作り、R2 の署名付き URL を 7 日間有効にする。
  5. 5取り込みは必ず dry-run を先に行い、レポートを確認してから適用。schema_version が新しすぎる場合は失敗として理由を出す。
  6. 6AI は要約と衝突の解決案だけを出す。適用は人が押す。
  7. 7参考表示。実行は CLI から（API トークンや Cloudflare の権限は画面に入力させない）。

表示データ

  • sync_changes（最新 rev、接続ごとの最終 rev）
  • login_sessions（auth_kind、端末、最終アクセス）
  • data_transfers（種類、状態、件数、サイズ、manifest、R2 キー）
  • projects.key、watch.toml のひな形（packages/bundle）

操作

  • コマンドをコピー（tester 以上）
  • CLI の接続を切る（自分の接続 / manager 以上はメンバーの接続）
  • 書き出す（manager 以上。ログを含めるのは admin のみ）
  • 取り込みの dry-run と適用（manager 以上）

AI の役割

取り込みレポートの要約と、衝突ごとの解決案（どちらを残すかと根拠）。AI は適用しない。

この画面の完了条件

  • 表示したコマンドを空のフォルダで実行すると、indx-watch/ ができ、./iw login && ./iw clone で作業コピーがそろう。
  • CLI の接続一覧に、各接続の方式・最後の同期・遅れが出て、「接続を切る」と次の CLI 操作で再ログインを求められる。activity_log に残る。
  • フル書き出し → 空のインスタンスに取り込み → 再書き出しで、manifest.json の件数と全ハッシュが一致する（SPEC-10）。
  • 取り込みは dry-run のレポート（追加・更新・衝突・番号の振り直し）を必ず経由し、衝突が残っていると適用できない。
  • ログを含める書き出しは admin だけができ、書き出したことが export.downloaded として記録される。
  • tester には書き出し・取り込みが表示されず、guest はこの画面に入れない（403 が記録される）。
  • 日本語・英語の両方で表示できる。

状態のバリエーション

状態表示
tester 視点「作業コピーを始める」と、自分の CLI 接続だけを表示。書き出し・取り込み・履歴・複製は出さない。
guestこの画面には入れない（ナビにも出ない）。CLI のログインも Access のポリシーで拒否される。直接 URL を開くと 403 と案内文を表示し、試行を記録する。
書き出し中履歴の行が「作成中」になり、進み具合（件数 / 全体）を表示。完了するとダウンロードのリンクが出る。
書き出し失敗「失敗」と理由（例: 証拠ファイル 3 件が R2 にない）を表示し、[もう一度] を出す。部分的なアーカイブは渡さない。
取り込みに衝突あり[適用] を無効にし、衝突ごとに「手元の値 / サーバーの値 / AI の解決案」を並べる。すべて選び終えると適用できる。
CLI がまだ誰も接続していない接続一覧の代わりに「まだ CLI からの接続はありません」と、作業コピーを始める手順への案内を表示。
