# 0012. Apache-2.0 and the Developer Certificate of Origin

- Status: accepted
- Date: 2026-11-19

## Decision

The project is licensed under Apache-2.0 (patent grant, enterprise-friendly). Contributions are accepted under the DCO: each commit carries `Signed-off-by:` (`git commit -s`). No CLA.

## Consequences

Low friction for contributors; a DCO check runs on pull requests.

## Alternatives considered

- **MIT** — no explicit patent grant.
- **CLA** — more friction; not needed without dual licensing plans.
