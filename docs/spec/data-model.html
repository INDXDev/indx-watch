SPEC-04 · データモデル

データモデル（D1 / R2）

INDX Watch のすべての情報は Cloudflare D1（SQLite）に入り、ファイル本体だけを R2 に置きます。このページの DDL が実装の起点です。実装後は packages/db/schema.ts とこのページを同じコミットで更新します。

状態 ドラフト v0.1更新 2026-11-19関連 ドメインモデル · アーキテクチャ

方針

  • D1 が単一の情報源。仕様・計画・実行・判定・AI 提案・監査ログまで 1 つの DB に入れる。GitHub や YAML は入出力にすぎない。
  • 主キーは TEXT の {prefix}_{ULID}。時系列で並ぶので、作成日時順のインデックスを別に持たなくてよい。
  • 日時は INTEGER（UNIX ミリ秒、UTC）。表示時に JST に変換。
  • 列挙値は TEXT + CHECK 制約。
  • 形が変わりやすい構造（手順・判定設定・設定値）は *_json の TEXT に入れ、形は packages/core の zod スキーマで定義・検証する。検索に使う値は列に出す。
  • 版を持つもの（TC・フィクスチャ）は「親（可変のメタ情報）+ 版（不変の中身）」の 2 テーブル。
  • 物理削除はしない（archived_at）。例外は保持期限を過ぎた証拠ファイル（保持と削除）。
  • 秘密値は保存しない。*_secret_ref に Secrets Store の参照名だけを保存する。

DDL

D1（SQLite）向け。実装では Drizzle のスキーマから同じ SQL を生成します。created_at / updated_at はすべてのテーブルに付けます（以下では一部省略せず記載）。

人・権限

CREATE TABLE users (
  id            TEXT PRIMARY KEY,                 -- usr_...
  email         TEXT NOT NULL UNIQUE,             -- Access JWT の email。agent は agent+watch@system
  name          TEXT NOT NULL,
  kind          TEXT NOT NULL DEFAULT 'human' CHECK (kind IN ('human','agent')),
  role          TEXT NOT NULL DEFAULT 'tester' CHECK (role IN ('admin','manager','tester','guest')),
  organization  TEXT,                             -- guest の所属（例: 株式会社サンプル）
  notify_json   TEXT NOT NULL DEFAULT '{}',       -- 通知設定
  last_seen_at  INTEGER,
  created_at    INTEGER NOT NULL,
  archived_at   INTEGER
);

CREATE TABLE project_members (
  project_id  TEXT NOT NULL REFERENCES projects(id),
  user_id     TEXT NOT NULL REFERENCES users(id),
  role        TEXT NOT NULL CHECK (role IN ('manager','tester','guest')),
  created_at  INTEGER NOT NULL,
  PRIMARY KEY (project_id, user_id)
);

CREATE TABLE project_counters (
  project_id  TEXT NOT NULL REFERENCES projects(id),
  kind        TEXT NOT NULL CHECK (kind IN ('FEAT','UC','TC','FX','PLAN','RUN')),
  next_value  INTEGER NOT NULL DEFAULT 1,
  PRIMARY KEY (project_id, kind)
);

どこで（プロジェクト・環境・リリース・デプロイ）

CREATE TABLE projects (
  id              TEXT PRIMARY KEY,               -- prj_...
  key             TEXT NOT NULL UNIQUE CHECK (key GLOB '[A-Z][A-Z0-9]*' AND length(key) BETWEEN 2 AND 6),
  name            TEXT NOT NULL,
  description     TEXT,
  repo_full_name  TEXT UNIQUE,                    -- indxdev/indx-shop
  default_branch  TEXT NOT NULL DEFAULT 'main',
  default_env_id  TEXT,                           -- 完了計算の既定環境
  settings_json   TEXT NOT NULL DEFAULT '{}',     -- ゲート閾値・モデル・判定ポリシー既定など
  created_at      INTEGER NOT NULL,
  updated_at      INTEGER NOT NULL,
  archived_at     INTEGER
);

CREATE TABLE environments (
  id                 TEXT PRIMARY KEY,            -- env_...
  project_id         TEXT NOT NULL REFERENCES projects(id),
  name               TEXT NOT NULL,               -- staging
  kind               TEXT NOT NULL CHECK (kind IN ('dev','staging','preview','uat','prod')),
  base_url           TEXT NOT NULL,
  access_kind        TEXT NOT NULL DEFAULT 'none' CHECK (access_kind IN ('none','basic','cf_access','ip_allowlist')),
  access_secret_ref  TEXT,                        -- Secrets Store の名前のみ
  entry_guide_md     TEXT NOT NULL DEFAULT '',    -- 入り方ガイド（人向け）
  reset_hook_json    TEXT,                        -- リセット / シード API の設定
  allowed_hosts_json TEXT NOT NULL DEFAULT '[]',  -- エージェントが遷移してよいホスト
  is_default         INTEGER NOT NULL DEFAULT 0,
  pr_number          INTEGER,                     -- preview のときの PR
  health_json        TEXT,                        -- 最終の接続テスト結果
  created_at         INTEGER NOT NULL,
  updated_at         INTEGER NOT NULL,
  archived_at        INTEGER,
  UNIQUE (project_id, name)
);

CREATE TABLE releases (
  id                TEXT PRIMARY KEY,             -- rel_...
  project_id        TEXT NOT NULL REFERENCES projects(id),
  version           TEXT NOT NULL,                -- v2.4.0
  title             TEXT,
  status            TEXT NOT NULL DEFAULT 'planning' CHECK (status IN ('planning','testing','ready','released')),
  target_date       TEXT,                         -- YYYY-MM-DD（JST の暦日）
  github_milestone  INTEGER,
  approved_by       TEXT REFERENCES users(id),    -- Go 承認者
  approved_at       INTEGER,
  created_at        INTEGER NOT NULL,
  updated_at        INTEGER NOT NULL,
  UNIQUE (project_id, version)
);

CREATE TABLE deployments (
  id              TEXT PRIMARY KEY,               -- dep_...
  project_id      TEXT NOT NULL REFERENCES projects(id),
  environment_id  TEXT NOT NULL REFERENCES environments(id),
  release_id      TEXT REFERENCES releases(id),
  commit_sha      TEXT NOT NULL,
  ref             TEXT,                           -- ブランチ / タグ
  pr_number       INTEGER,
  url             TEXT,                           -- 実際の URL（preview は PR ごと）
  source          TEXT NOT NULL CHECK (source IN ('github','manual')),
  github_deployment_id INTEGER,
  status          TEXT NOT NULL DEFAULT 'active' CHECK (status IN ('active','superseded','failed')),
  deployed_at     INTEGER NOT NULL,
  created_at      INTEGER NOT NULL
);
CREATE INDEX deployments_env_time ON deployments(environment_id, deployed_at DESC);
CREATE INDEX deployments_release ON deployments(release_id);

仕様（機能・ユースケース・完了条件・テストケース）

CREATE TABLE features (
  id           TEXT PRIMARY KEY,                  -- fea_...
  project_id   TEXT NOT NULL REFERENCES projects(id),
  number       INTEGER NOT NULL,                  -- FEAT-3
  title        TEXT NOT NULL,
  description  TEXT,
  sort         INTEGER NOT NULL DEFAULT 0,
  created_at   INTEGER NOT NULL,
  updated_at   INTEGER NOT NULL,
  archived_at  INTEGER,
  UNIQUE (project_id, number)
);

CREATE TABLE use_cases (
  id              TEXT PRIMARY KEY,               -- uc_...
  project_id      TEXT NOT NULL REFERENCES projects(id),
  feature_id      TEXT NOT NULL REFERENCES features(id),
  number          INTEGER NOT NULL,               -- UC-12
  title           TEXT NOT NULL,                  -- ゲストがクーポンを適用して購入する
  actor           TEXT NOT NULL,                  -- ゲスト
  goal            TEXT NOT NULL,                  -- 割引価格で購入を完了したい
  description_md  TEXT NOT NULL DEFAULT '',
  priority        TEXT NOT NULL DEFAULT 'P2' CHECK (priority IN ('P0','P1','P2','P3')),
  status          TEXT NOT NULL DEFAULT 'draft' CHECK (status IN ('draft','ready','deprecated')),
  origin          TEXT NOT NULL DEFAULT 'human' CHECK (origin IN ('human','ai')),
  suggestion_id   TEXT REFERENCES ai_suggestions(id),
  sort            INTEGER NOT NULL DEFAULT 0,
  created_by      TEXT NOT NULL REFERENCES users(id),
  created_at      INTEGER NOT NULL,
  updated_at      INTEGER NOT NULL,
  UNIQUE (project_id, number)
);

CREATE TABLE acceptance_criteria (
  id           TEXT PRIMARY KEY,                  -- ac_...
  use_case_id  TEXT NOT NULL REFERENCES use_cases(id),
  seq          INTEGER NOT NULL,                  -- AC-12.2 の 2
  text         TEXT NOT NULL,
  created_at   INTEGER NOT NULL,
  updated_at   INTEGER NOT NULL,
  archived_at  INTEGER,
  UNIQUE (use_case_id, seq)
);

CREATE TABLE test_cases (
  id                  TEXT PRIMARY KEY,           -- tc_...
  project_id          TEXT NOT NULL REFERENCES projects(id),
  use_case_id         TEXT NOT NULL REFERENCES use_cases(id),
  number              INTEGER NOT NULL,           -- TC-128
  title               TEXT NOT NULL,
  priority            TEXT NOT NULL CHECK (priority IN ('P0','P1','P2','P3')),
  mode                TEXT NOT NULL DEFAULT 'manual' CHECK (mode IN ('manual','agent','script','hybrid')),
  status              TEXT NOT NULL DEFAULT 'draft' CHECK (status IN ('draft','ready','deprecated')),
  current_version_id  TEXT,                       -- test_case_versions.id
  owner_id            TEXT REFERENCES users(id),
  origin              TEXT NOT NULL DEFAULT 'human' CHECK (origin IN ('human','ai')),
  suggestion_id       TEXT REFERENCES ai_suggestions(id),
  tags_json           TEXT NOT NULL DEFAULT '[]', -- ["smoke","coupon"]
  approved_by         TEXT REFERENCES users(id),
  approved_at         INTEGER,
  created_at          INTEGER NOT NULL,
  updated_at          INTEGER NOT NULL,
  UNIQUE (project_id, number)
);
CREATE INDEX test_cases_uc ON test_cases(use_case_id);

CREATE TABLE test_case_versions (
  id                    TEXT PRIMARY KEY,         -- tcv_...
  test_case_id          TEXT NOT NULL REFERENCES test_cases(id),
  version               INTEGER NOT NULL,         -- 1, 2, 3...
  preconditions_md      TEXT NOT NULL DEFAULT '',
  steps_json            TEXT NOT NULL,            -- Step[]（下記）
  judges_json           TEXT NOT NULL DEFAULT '[]',
  decision_policy_json  TEXT,                     -- null ならプロジェクト既定
  fixture_refs_json     TEXT NOT NULL DEFAULT '[]',
  evidence_policy       TEXT NOT NULL DEFAULT 'every_step' CHECK (evidence_policy IN ('every_step','on_fail','final_only')),
  script                TEXT,                     -- mode=script のとき Playwright コード
  change_note           TEXT NOT NULL DEFAULT '',
  origin                TEXT NOT NULL DEFAULT 'human' CHECK (origin IN ('human','ai')),
  created_by            TEXT NOT NULL REFERENCES users(id),
  created_at            INTEGER NOT NULL,
  UNIQUE (test_case_id, version)
);

CREATE TABLE test_case_criteria (
  test_case_id  TEXT NOT NULL REFERENCES test_cases(id),
  criterion_id  TEXT NOT NULL REFERENCES acceptance_criteria(id),
  PRIMARY KEY (test_case_id, criterion_id)
);
CREATE INDEX test_case_criteria_ac ON test_case_criteria(criterion_id);

データ（フィクスチャ）

CREATE TABLE fixtures (
  id                  TEXT PRIMARY KEY,           -- fx_...
  project_id          TEXT NOT NULL REFERENCES projects(id),
  number              INTEGER NOT NULL,           -- FX-3
  name                TEXT NOT NULL,
  kind                TEXT NOT NULL CHECK (kind IN ('dataset','seed','file','account')),
  description         TEXT NOT NULL DEFAULT '',
  environment_id      TEXT REFERENCES environments(id),  -- null は全環境共通
  current_version_id  TEXT,
  created_at          INTEGER NOT NULL,
  updated_at          INTEGER NOT NULL,
  archived_at         INTEGER,
  UNIQUE (project_id, number)
);

CREATE TABLE fixture_versions (
  id            TEXT PRIMARY KEY,                 -- fxv_...
  fixture_id    TEXT NOT NULL REFERENCES fixtures(id),
  version       INTEGER NOT NULL,
  r2_key        TEXT,                             -- account は null
  content_type  TEXT,
  size          INTEGER,
  sha256        TEXT,
  summary_json  TEXT NOT NULL DEFAULT '{}',       -- 列名・行数・先頭行など（一覧と AI 用）
  public_json   TEXT,                             -- account の公開情報（ユーザー名など）
  secret_ref    TEXT,                             -- account の秘密の参照名
  change_note   TEXT NOT NULL DEFAULT '',
  restored_from INTEGER,                          -- 「この版に戻す」の元の版番号
  origin        TEXT NOT NULL DEFAULT 'human' CHECK (origin IN ('human','ai')),
  created_by    TEXT NOT NULL REFERENCES users(id),
  created_at    INTEGER NOT NULL,
  UNIQUE (fixture_id, version)
);

計画

CREATE TABLE test_plans (
  id          TEXT PRIMARY KEY,                   -- pln_...
  project_id  TEXT NOT NULL REFERENCES projects(id),
  release_id  TEXT REFERENCES releases(id),
  number      INTEGER NOT NULL,                   -- PLAN-4
  title       TEXT NOT NULL,
  status      TEXT NOT NULL DEFAULT 'draft' CHECK (status IN ('draft','active','closed')),
  due_date    TEXT,
  created_by  TEXT NOT NULL REFERENCES users(id),
  created_at  INTEGER NOT NULL,
  updated_at  INTEGER NOT NULL,
  UNIQUE (project_id, number)
);

CREATE TABLE plan_items (
  id              TEXT PRIMARY KEY,               -- pli_...
  plan_id         TEXT NOT NULL REFERENCES test_plans(id),
  test_case_id    TEXT NOT NULL REFERENCES test_cases(id),
  environment_id  TEXT NOT NULL REFERENCES environments(id),
  assignee_id     TEXT REFERENCES users(id),      -- null は未割り当て
  priority        TEXT NOT NULL CHECK (priority IN ('P0','P1','P2','P3')),
  due_date        TEXT,
  status          TEXT NOT NULL DEFAULT 'todo' CHECK (status IN ('todo','in_progress','done','blocked')),
  latest_run_id   TEXT,                           -- 表示高速化用（runs 確定時に更新）
  dataset_row     TEXT,                           -- データ駆動時の行キー
  note            TEXT,
  sort            INTEGER NOT NULL DEFAULT 0,
  created_at      INTEGER NOT NULL,
  updated_at      INTEGER NOT NULL,
  UNIQUE (plan_id, test_case_id, environment_id, dataset_row)
);
CREATE INDEX plan_items_assignee ON plan_items(assignee_id, status, due_date);

CREATE TABLE schedules (
  id              TEXT PRIMARY KEY,               -- sch_...
  project_id      TEXT NOT NULL REFERENCES projects(id),
  name            TEXT NOT NULL,                  -- 毎朝の P0 スモーク
  environment_id  TEXT NOT NULL REFERENCES environments(id),
  selector_json   TEXT NOT NULL,                  -- {"tags":["smoke"],"priority":["P0"],"modes":["agent","script"]}
  cron            TEXT NOT NULL,                  -- UTC。0 22 * * * = JST 7:00
  enabled         INTEGER NOT NULL DEFAULT 1,
  last_run_at     INTEGER,
  created_at      INTEGER NOT NULL,
  updated_at      INTEGER NOT NULL
);

実行・証拠・判定

CREATE TABLE runs (
  id                     TEXT PRIMARY KEY,        -- run_...
  project_id             TEXT NOT NULL REFERENCES projects(id),
  number                 INTEGER NOT NULL,        -- RUN-1033
  test_case_id           TEXT NOT NULL REFERENCES test_cases(id),
  test_case_version_id   TEXT NOT NULL REFERENCES test_case_versions(id),
  plan_item_id           TEXT REFERENCES plan_items(id),   -- 計画外の単発実行は null
  deployment_id          TEXT NOT NULL REFERENCES deployments(id),
  environment_id         TEXT NOT NULL REFERENCES environments(id),
  executor_kind          TEXT NOT NULL CHECK (executor_kind IN ('human','agent','script')),
  executor_id            TEXT NOT NULL REFERENCES users(id),
  trigger                TEXT NOT NULL DEFAULT 'manual' CHECK (trigger IN ('manual','plan','schedule','github','mcp')),
  state                  TEXT NOT NULL DEFAULT 'queued' CHECK (state IN ('queued','running','judging','completed','error')),
  verdict                TEXT CHECK (verdict IN ('pass','fail','blocked','skipped','needs_review')),
  verdict_reason         TEXT,                    -- 判定ポリシーの説明（どのルールで決まったか）
  decision_policy_json   TEXT,                    -- 実行時に使った判定ポリシー（既定と TC 上書きをマージ済み）。再計算でも結果が変わらないように保存
  fixture_versions_json  TEXT NOT NULL DEFAULT '{}',  -- {"FX-3":4,"FX-11":2}
  params_json            TEXT NOT NULL DEFAULT '{}',  -- データ駆動の行の値
  workflow_instance_id   TEXT,                    -- Cloudflare Workflows のインスタンス
  summary                TEXT,                    -- AI 要約（失敗理由など）
  cost_json              TEXT,                    -- {"input_tokens":..., "output_tokens":..., "browser_ms":...}
  error_json             TEXT,
  started_at             INTEGER,
  finished_at            INTEGER,
  created_at             INTEGER NOT NULL,
  UNIQUE (project_id, number)
);
CREATE INDEX runs_tc_time ON runs(test_case_id, created_at DESC);
CREATE INDEX runs_deployment ON runs(deployment_id);
CREATE INDEX runs_review ON runs(project_id, verdict) WHERE verdict = 'needs_review';

CREATE TABLE run_steps (
  id           TEXT PRIMARY KEY,                  -- rst_...
  run_id       TEXT NOT NULL REFERENCES runs(id),
  seq          INTEGER NOT NULL,
  instruction  TEXT NOT NULL,                     -- 実行時点の手順をコピー
  expected     TEXT NOT NULL DEFAULT '',
  verdict      TEXT CHECK (verdict IN ('pass','fail','blocked','skipped','needs_review')),
  note         TEXT,                              -- 人のメモ / 実際の結果
  actions_json TEXT,                              -- エージェントが行った操作の列
  started_at   INTEGER,
  finished_at  INTEGER,
  UNIQUE (run_id, seq)
);

CREATE TABLE evidence (
  id            TEXT PRIMARY KEY,                 -- evd_...
  run_id        TEXT NOT NULL REFERENCES runs(id),
  run_step_id   TEXT REFERENCES run_steps(id),
  kind          TEXT NOT NULL CHECK (kind IN ('screenshot','dom','a11y','console','network','trace','transcript','upload')),
  r2_key        TEXT NOT NULL,
  content_type  TEXT NOT NULL,
  size          INTEGER NOT NULL,
  caption       TEXT,
  created_by    TEXT NOT NULL REFERENCES users(id),
  created_at    INTEGER NOT NULL,
  retain        INTEGER NOT NULL DEFAULT 0,       -- 1 = 保持期限の対象外（リリース最終結果・ベースライン採用時）
  expires_at    INTEGER                           -- 保持期限（retain = 1 なら null）
);
CREATE INDEX evidence_run ON evidence(run_id, run_step_id);

CREATE TABLE judgements (
  id              TEXT PRIMARY KEY,               -- jdg_...
  run_id          TEXT NOT NULL REFERENCES runs(id),
  run_step_id     TEXT REFERENCES run_steps(id),  -- null は実行全体への判定
  judge_kind      TEXT NOT NULL CHECK (judge_kind IN ('assert','visual','llm','human')),
  verdict         TEXT NOT NULL CHECK (verdict IN ('pass','fail','blocked','skipped','needs_review')),
  confidence      REAL,                           -- llm / visual のみ 0..1
  reason          TEXT NOT NULL DEFAULT '',       -- human は必須（アプリで検証）
  evidence_ids_json TEXT NOT NULL DEFAULT '[]',   -- 根拠にした証拠
  model           TEXT,                           -- claude-sonnet-5-5 など
  prompt_version  TEXT,                           -- judge.llm@3
  raw_json        TEXT,                           -- 構造化出力の生データ
  created_by      TEXT NOT NULL REFERENCES users(id),
  created_at      INTEGER NOT NULL
);
CREATE INDEX judgements_run ON judgements(run_id);

CREATE TABLE baselines (
  id              TEXT PRIMARY KEY,               -- bsl_...
  test_case_id    TEXT NOT NULL REFERENCES test_cases(id),
  environment_id  TEXT NOT NULL REFERENCES environments(id),
  step_seq        INTEGER NOT NULL,
  r2_key          TEXT NOT NULL,
  source_evidence_id TEXT REFERENCES evidence(id),
  approved_by     TEXT NOT NULL REFERENCES users(id),
  approved_at     INTEGER NOT NULL,
  superseded_at   INTEGER
);

外部連携・AI・記録

CREATE TABLE github_installations (
  id               TEXT PRIMARY KEY,
  installation_id  INTEGER NOT NULL UNIQUE,
  account_login    TEXT NOT NULL,                 -- indxdev
  created_at       INTEGER NOT NULL
);

CREATE TABLE issues (
  id           TEXT PRIMARY KEY,                  -- iss_...
  run_id       TEXT NOT NULL REFERENCES runs(id),
  provider     TEXT NOT NULL DEFAULT 'github',
  external_id  TEXT NOT NULL,                     -- Issue 番号
  url          TEXT NOT NULL,
  state        TEXT NOT NULL DEFAULT 'open' CHECK (state IN ('open','closed')),
  severity     TEXT CHECK (severity IN ('P0','P1','P2','P3')),
  created_by   TEXT NOT NULL REFERENCES users(id),
  created_at   INTEGER NOT NULL,
  updated_at   INTEGER NOT NULL
);

CREATE TABLE ai_suggestions (
  id              TEXT PRIMARY KEY,               -- sug_...
  project_id      TEXT NOT NULL REFERENCES projects(id),
  kind            TEXT NOT NULL CHECK (kind IN ('spec_import','tc_generate','impact','fixture','triage')),
  source_json     TEXT NOT NULL,                  -- 入力の参照（R2 キー、PR 番号、対象 ID）
  payload_json    TEXT NOT NULL,                  -- 提案本体（構造化出力）
  item_decisions_json TEXT NOT NULL DEFAULT '{}', -- 項目ごとの採否 {"uc:0":"accepted","tc:2":"rejected"}
  status          TEXT NOT NULL DEFAULT 'pending' CHECK (status IN ('pending','accepted','rejected','partial')),
  model           TEXT NOT NULL,
  prompt_version  TEXT NOT NULL,
  cost_json       TEXT,
  requested_by    TEXT NOT NULL REFERENCES users(id),
  decided_by      TEXT REFERENCES users(id),
  decided_at      INTEGER,
  created_at      INTEGER NOT NULL
);

CREATE TABLE comments (
  id           TEXT PRIMARY KEY,                  -- cmt_...
  project_id   TEXT NOT NULL REFERENCES projects(id),
  target_type  TEXT NOT NULL,                     -- use_case / test_case / run / plan_item / fixture
  target_id    TEXT NOT NULL,
  author_id    TEXT NOT NULL REFERENCES users(id),
  body_md      TEXT NOT NULL,
  created_at   INTEGER NOT NULL,
  updated_at   INTEGER NOT NULL
);
CREATE INDEX comments_target ON comments(target_type, target_id);

CREATE TABLE activity_log (
  id           TEXT PRIMARY KEY,                  -- act_...
  project_id   TEXT REFERENCES projects(id),
  actor_id     TEXT NOT NULL REFERENCES users(id),

  target_type  TEXT NOT NULL,

  diff_json    TEXT,                              -- 変更前後

主要クエリ

マイタスク（S01）

SELECT pi.*, tc.number, tc.title, tc.mode, e.name AS env_name, p.key AS project_key, r.verdict AS latest_verdict
FROM plan_items pi
JOIN test_plans pl ON pl.id = pi.plan_id AND pl.status = 'active'
JOIN test_cases tc ON tc.id = pi.test_case_id
JOIN environments e ON e.id = pi.environment_id
JOIN projects p ON p.id = tc.project_id
LEFT JOIN runs r ON r.id = pi.latest_run_id
WHERE pi.assignee_id = ?1 AND pi.status IN ('todo','in_progress','blocked')
ORDER BY CASE pi.priority WHEN 'P0' THEN 0 WHEN 'P1' THEN 1 WHEN 'P2' THEN 2 ELSE 3 END,
         pi.due_date IS NULL, pi.due_date, pi.sort;

リリース × 環境ごとの TC の最新判定（S02 / S03 の元データ）

WITH latest AS (
  SELECT r.test_case_id, r.verdict, r.test_case_version_id,
         ROW_NUMBER() OVER (PARTITION BY r.test_case_id ORDER BY r.created_at DESC) AS rn
  FROM runs r
  JOIN deployments d ON d.id = r.deployment_id
  WHERE d.release_id = ?1 AND r.environment_id = ?2 AND r.state = 'completed'
)
SELECT tc.id, tc.priority, tc.current_version_id,
       l.verdict, (l.test_case_version_id = tc.current_version_id) AS on_current_version
FROM test_cases tc
LEFT JOIN latest l ON l.test_case_id = tc.id AND l.rn = 1
WHERE tc.project_id = ?3 AND tc.status = 'ready';

AC・UC の状態と網羅率はこの結果と test_case_criteria から packages/core の純粋関数で計算します（SQL に集約ロジックを持たせない。ユニットテストしやすくするため）。件数が増えたら、実行確定時に plan_items.latest_run_id と同様のキャッシュ列を追加します。

アクセス制御

D1 には行レベルセキュリティがないため、すべてのクエリは apps/web/lib/authz.ts の関数を通し、プロジェクトとロールで絞ります。

ロール読み取り書き込み
adminすべてすべて（プロジェクト作成、ユーザー管理、設定）
managerメンバーのプロジェクトすべて仕様の承認、計画・アサイン、ゲート承認、ベースライン承認、環境・フィクスチャ
testerメンバーのプロジェクトすべて仕様・TC の作成（draft）、フィクスチャ編集、実行、判定、コメント
guest自分が担当の計画アイテムと、その TC 版・環境の入り方・必要なフィクスチャのみ担当アイテムの実行・判定・コメントのみ

保持と削除

  • 証拠ファイルは 180 日で R2 ライフサイクルにより削除。D1 の evidence 行は残し、expires_at を過ぎたものは「期限切れ」と表示する。
  • ベースラインに採用された証拠、リリースの最終結果に使われた証拠は retain = 1 にして残す（日次の Cron で R2 側を保持用のキー retained/ にコピー）。
  • D1 は Time Travel（30 日）で復元可能。加えて毎日 D1 をエクスポートし、別バケット indx-watch-backup に保存する（90 日保持）。
  • ユーザーの退職・顧客の契約終了時は users.archived_at を設定し、Access ポリシーから外す。作成物と履歴は残す。

マイグレーション運用

  1. packages/db/schema.ts を変更し、このページの DDL を同じコミットで更新する。
  2. pnpm db:generate で SQL を生成し、packages/db/migrations/NNNN_*.sql を確認する。

  4. PR をマージすると GitHub Actions が wrangler d1 migrations apply --remote を実行する。列の削除・型変更は 2 段階（追加 → 移行 → 次のリリースで削除）で行う。
