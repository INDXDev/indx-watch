INDX Watch · 設計ドキュメント

どこを・どうすれば完了か、
全員が同じ画面で分かる E2E テスト基盤

INDX Watch は Cloudflare 上でセルフホストする、社内向けの AI ネイティブな E2E テスト / QA 管理プラットフォームです。ユースケースと完了条件、テストケース、フィクスチャ、環境、リリースとデプロイ、アサイン、実行結果と証拠、AI の判定を 1 つのデータベースで管理します。

フェーズ M0 完了 → M1 着手可能（開発プラン）更新 2026-11-19リポジトリ indxdev/indx-watch

ドキュメントの 2 層構造

第 1 層が「何を・なぜ」の正（仕様）、第 2 層が「どう見えるか・どう作るか」です。第 2 層は必ず第 1 層の言葉と ID に従います。食い違ったら第 1 層を直してから第 2 層を合わせます。

決まっていること

形式が正、ロックインしない

単一の情報源は Watch Bundle 形式。Cloudflare は共有と同期の中心。indx-watch/ に置けば CLI で一瞬で取り出し・同期・デプロイ。

Next.js + Worker 2 つ

UI と API は Next.js（vinext で Workers）。実行は Workflows・Queues・Browser Run のランナー Worker。

社内だけが入れる

Cloudflare Access を Worker に付け、社内ドメインと招待した顧客のメールだけ許可。

日本語と英語

画面も、ユースケースや手順の中身も日英で使える。原文 + AI 翻訳 + 人の確認。

作業の記録

ログイン（失敗含む）・場所・端末・操作・作業時間を記録。目的と閲覧権限を決めて告知。

完了は計算で決まる

ユースケースはすべての完了条件が合格で完了。リリースは Go / No-Go 条件で判定。

AI は提案、人が承認

AI の仕様は draft で入る。AI の判定は信頼度付きで、足りなければ人のレビューへ。

すべて版で残す

テストケースとフィクスチャは不変の版を積み上げ、実行は使った版を記録する。

サンプルデータについて

ドキュメント中の「INDX Shop（SHOP）」、ドメイン *.example.com / watch.indx.example、人物名はすべて説明用のサンプルです。実際のテスト対象リポジトリと環境は テスト対象の登録 の手順で定義します。
